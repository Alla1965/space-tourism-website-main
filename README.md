# Space Tourism Website

A multi-page space tourism website.  
Users can explore space destinations, meet the crew, and learn about space technology.

## Overview

This project was built as a Frontend Mentor challenge.  
The goal was to practice creating a responsive multi-page website using HTML, CSS, and JavaScript.

## Features

- Multi-page website layout
- Home page with hero section
- Destination page with different planets
- Crew page with crew member information
- Technology page with space technology details
- Responsive design for mobile, tablet, and desktop screens
- Interactive navigation between sections

## Technologies Used

- HTML
- CSS
- JavaScript
- Vite
- JSON
